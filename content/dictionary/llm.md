A large language model (LLM) is a kind of {{< term "ai" >}} trained on enormous amounts of text to predict which words come next. That one skill lets it answer questions, summarise, translate and write code, and it is the engine behind chatbots, the programs you talk to in a chat window. It produces fluent text whether or not the facts are right, so its sources and claims need checking. It also treats any text it reads as possible instructions, which makes it open to {{< term "prompt-injection" >}}.
