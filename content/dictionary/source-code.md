Source code is a program as its authors wrote it: text in a programming language that people can read and change. It is turned into the files a computer actually runs. When the source is public, as with {{< term "open-source" "open-source" >}} software, anyone can read exactly what a program does instead of trusting its description, and comments in it often explain why it does it.
