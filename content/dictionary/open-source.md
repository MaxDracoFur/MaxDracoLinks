Open-source software is published with its {{< term "source-code" "source code" >}} under a licence that lets anyone read it, change it and pass it on. Much of the software that runs the internet is open source, from {{< term "linux" >}} to web servers. Being able to read the code makes it possible to check it for flaws, though that only helps when someone actually does.
